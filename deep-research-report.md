# Riset Strategis Website Raessa Wedding Organizer — Brand, Layanan, UI/UX, Visual Identity, dan Arah Pengembangan

## Temuan utama dan batasan audit

Saya menempatkan **Raessa Wedding Organizer sebagai objek brand**, bukan sekadar referensi visual. Artinya, arah website sebaiknya dibangun dari apa yang benar-benar dijual Raessa, bagaimana mereka berkomunikasi di media sosial, siapa calon konsumennya, dan tindakan apa yang paling bernilai setelah pengunjung datang ke website.

Dari sumber yang dapat diverifikasi saat ini, Raessa beroperasi di **Balikpapan** dan akun Instagram yang Anda kirim terindeks sebagai **“MUA & WO Balikpapan”**. Bio yang terindeks menyebut empat kelompok layanan secara eksplisit: **WO, Décor, Gown & Accessories Rental, dan Catering**, sedangkan identitas “MUA” muncul pada nama profil. Sumber pihak ketiga WithYou, yang menyatakan profilnya disusun dari akun resmi vendor, juga mengelompokkan Raessa ke dalam wedding organizer, rias & makeup, dekorasi, gaun & busana, dan katering. citeturn0search1turn9search4

Ada satu keterbatasan penting: halaman Instagram langsung tidak dapat di-fetch penuh oleh crawler pada saat riset ini, sehingga saya **tidak akan berpura-pura telah melakukan pixel-level audit terhadap seluruh grid Instagram, logo, highlight, dan setiap postingan**. Analisis di bawah ditriangulasi dari hasil indeks Instagram, posting Facebook yang terhubung dengan aktivitas Raessa, halaman vendor, serta hasil pencarian terbaru. Karena itu, palet warna yang saya rekomendasikan adalah **strategic website palette**, bukan klaim bahwa warna tersebut merupakan kode warna resmi logo Raessa. citeturn0search1turn1search0turn9search4

Justru dari keterbatasan tersebut muncul satu prinsip penting: **website Raessa jangan dibuat sebagai salinan Instagram**. Website perlu menjadi lapisan brand yang lebih stabil, elegan, informatif, dan berorientasi konversi; Instagram tetap menjadi mesin distribusi konten dan social proof.

### Kesimpulan awal

Menurut saya, positioning website yang paling tepat bukan sekadar:

> “Wedding Organizer Balikpapan”

melainkan:

> **Raessa — One-Stop Wedding Partner in Balikpapan**

Ini merupakan positioning yang saya simpulkan dari rentang layanan Raessa: wedding organizer, makeup, dekorasi, gaun/attire beserta aksesori, dan catering. Dengan kombinasi tersebut, calon pengantin pada dasarnya dapat datang dengan sebuah konsep kemudian membicarakan banyak kebutuhan wedding melalui satu brand. citeturn0search1turn9search4

Website kita nantinya harus membuat value tersebut **terlihat dalam beberapa detik pertama**, bukan meminta pengunjung menggali feed Instagram terlebih dahulu.

## Arah visual dan positioning yang paling cocok

### Kepribadian brand yang saya rekomendasikan

Dari karakter layanan dan komunikasi Raessa, saya tidak menyarankan website bergaya “girly wedding” dengan dominasi pink pastel, bunga di semua sudut, terlalu banyak tulisan script, atau glitter/gold berlebihan.

Arahnya lebih tepat:

> **Elegant + Warm + Romantic + Modern + Trustworthy**

Dengan proporsi kira-kira:

**40% Elegant  
25% Warm  
20% Modern  
10% Romantic  
5% Playful**

“Romantic” tidak harus berarti pink. Ia bisa muncul melalui fotografi, whitespace, serif typography, curve halus, dan animasi lembut.

Hal ini penting karena portfolio Raessa sendiri mencakup konsep yang cukup beragam, dari soft/elegant dan intimate sampai colorful serta outdoor. citeturn2search0turn2search10turn2search13turn2search15

### Palet warna utama yang saya rekomendasikan

Saya menyarankan **Warm Editorial Wedding Palette** berikut.

| Role | Warna | Hex | Pemakaian |
|---|---|---:|---|
| Canvas | Warm Ivory | `#FAF7F2` | background utama |
| Primary Text | Espresso | `#2F2522` | headline, body, navbar |
| Luxury Accent | Champagne Gold | `#C6A66A` | garis, icon, hover, ornamen |
| Natural Accent | Muted Sage | `#7D8A78` | labels, cards, botanical feel |
| Romantic Accent | Dusty Blush | `#D8B7B1` | section tertentu / testimonial |
| Strong CTA | Deep Olive | `#4E5A49` | tombol konsultasi |
| Clean | White | `#FFFFFF` | card/background kontras |

Visualnya akan terasa kurang lebih:

`Ivory → Espresso → Champagne → Sage → Blush`

bukan:

`Pink → Pink → Gold → Flower → Pink`

Ini saya anggap lebih sustainable secara visual karena **fotografi wedding menjadi sumber warna utama**, sedangkan UI menjadi frame yang konsisten.

### Aksesibilitas palet

WCAG 2.2 mensyaratkan kontras teks normal minimal **4.5:1**, sedangkan large text dapat menggunakan 3:1. citeturn8search0turn8search4

Saya menghitung pasangan warna di atas dan hasil pentingnya:

| Pasangan | Contrast | Penggunaan |
|---|---:|---|
| Espresso `#2F2522` / Ivory `#FAF7F2` | **13.95:1** | Sangat aman untuk body |
| White / Espresso | **14.91:1** | Sangat aman |
| White / Deep Olive `#4E5A49` | **7.29:1** | Sangat baik untuk CTA |
| Espresso / Dusty Blush | **8.04:1** | Aman |
| Espresso / Champagne | **6.43:1** | Aman |
| Sage / Ivory | **3.40:1** | Jangan untuk body kecil |
| Champagne / Ivory | **2.17:1** | Jangan digunakan sebagai teks kecil |

Dengan kata lain, **gold digunakan untuk aksen, bukan untuk paragraf tipis di atas putih**. Ini salah satu kesalahan yang sangat sering membuat website wedding terlihat cantik tetapi sulit dibaca.

Contoh nanti:

```css
:root {
  --color-bg: #FAF7F2;
  --color-surface: #FFFFFF;

  --color-text: #2F2522;
  --color-accent: #C6A66A;
  --color-sage: #7D8A78;
  --color-blush: #D8B7B1;

  --color-primary: #4E5A49;
}
```

Struktur seperti ini juga membuat perubahan tema jauh lebih mudah ketika development dimulai.

### Typeface utama

Pilihan pertama saya adalah:

**Cormorant Garamond + DM Sans**

Cormorant Garamond memang dirancang sebagai keluarga display serif, sedangkan DM Sans merupakan geometric sans-serif low-contrast yang ditujukan untuk tetap efektif pada ukuran teks lebih kecil. Kombinasi itu tepat untuk pola yang kita butuhkan: headline editorial/romantic, tetapi navigasi dan body tetap sangat jelas. citeturn7search0turn7search1

Contoh hierarki:

> **Cormorant Garamond**  
> Your Wedding, Beautifully Orchestrated

dan:

> **DM Sans**  
> Wedding Organizer • Decoration • Makeup • Attire • Catering

Saya merekomendasikan:

```text
H1/H2     → Cormorant Garamond
H3        → Cormorant Garamond / DM Sans
Body      → DM Sans
Navigation→ DM Sans
Button    → DM Sans
Caption   → DM Sans
```

### Alternatif yang lebih modern

Pilihan kedua:

> **Playfair Display + Manrope**

Playfair adalah display typeface transitional yang memang diperuntukkan untuk ukuran besar, sedangkan Manrope adalah sans-serif modern open-source. citeturn7search2turn7search3

Karakter pasangan ini lebih:

**luxury hotel / premium wedding**

sementara Cormorant + DM Sans lebih:

**romantic editorial / boutique wedding.**

Untuk Raessa, saya sementara memberi kemenangan kepada:

> **Cormorant Garamond + DM Sans**

### Tentang script font

Script font seperti Great Vibes memang memiliki bentuk flowing/calligraphic dan secara tematik mudah diasosiasikan dengan wedding. citeturn7search14

Tetapi saya tidak akan menjadikannya font heading utama.

Kalaupun digunakan, cukup untuk:

> “Our Story”

atau signature dekoratif.

Jangan:

> seluruh hero, menu, judul layanan, button, dan testimonial menggunakan script.

Kesan premium justru sering muncul ketika kita **menahan diri**.

## Interaksi dan konsep UI tanpa framework

Keputusan Anda menggunakan **HTML + CSS + JavaScript murni** tidak menghalangi kita membuat website yang terasa premium.

Bahkan untuk website vendor wedding yang sebagian besar berupa content/portfolio, pendekatan sederhana seperti ini dapat menghasilkan halaman yang sangat cepat selama image loading, layout dan JavaScript dijaga. Google menggunakan LCP, INP, dan CLS sebagai Core Web Vitals; threshold “good” yang direkomendasikan adalah LCP ≤2.5 detik, INP ≤200 ms, dan CLS ≤0.1. citeturn8search2turn8search6

### Jenis interaksi yang saya pilih

Bukan “semakin banyak animasi semakin bagus”.

Prinsipnya:

> **Movement should support emotion and hierarchy.**

#### Hero reveal

Saat halaman terbuka:

```text
Image → subtle zoom
RAESSA → fade
Headline → reveal upward
CTA → fade
```

Durasi sekitar 700–1200 ms sudah cukup terasa cinematic.

Tidak perlu WebGL.

Tidak perlu GSAP.

Tidak perlu Three.js.

### Scroll reveal

Saat user scroll:

```text
image
        ↗ subtle reveal

headline
        ↑ reveal

caption
        opacity
```

Semua dapat dibuat native.

Tetapi pengguna yang memilih reduced motion seharusnya tidak dipaksa mengikuti animasi non-esensial. WCAG secara eksplisit membahas animation-from-interactions dan merekomendasikan penghormatan terhadap `prefers-reduced-motion`. citeturn8search1turn8search5

Contoh prinsip CSS kita nanti:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

### Struktur HTML tetap semantic

Kita tidak akan membuat semuanya sebagai `<div>`.

HTML Standard memberikan elemen semantik khusus seperti `nav` untuk navigation section, dan penggunaan semantic structure membantu dokumen memiliki arti yang lebih jelas. citeturn8search3turn8search10

Secara konseptual:

```html
<header>
  <nav></nav>
```
